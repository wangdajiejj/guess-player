# 怎么把它跑起来

> 这份文档只回答一个问题：**我现在就想看看它长什么样，具体点哪几下。**
> 部署上线的完整流程在 `docs/05-deployment.md`。

**有两条路，先选一条：**

| | 路线 A：本地测试模式 | 路线 B：真·云环境 |
| --- | --- | --- |
| 适合 | 想看效果、试玩法、改完 UI 先看一眼 | 要提审、要上线、要给别人用 |
| 要不要 AppID | 不要 | 要（且要实名） |
| 要不要备案 | 不要 | 要，**1~20 个工作日** |
| 要不要建集合 / 传云函数 | 不要 | 要 |
| 花多久 | **2 分钟** | 30 分钟 + 等备案 |
| 数据存哪 | 你手机/模拟器的本地存储 | 微信云数据库 |

⚠️ **本地测试模式绝对不能用来提审。** 它把比对逻辑和 500 人答案池放进了客户端，
别人反编译后遍历候选池就能试出每天的答案。提审前必须走 `scripts\关闭本地测试-提审前必点.bat`。

# 路线 A：本地测试模式（2 分钟，推荐先走这条）

## 第 1 步：装微信开发者工具

<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

装 **稳定版 Stable Build**（别装 Nightly，坑多）。一路下一步即可。

## 第 2 步：双击脚本

打开 `guess-player\scripts\`，双击：

```
开启本地测试.bat
```

它会做两件事，跑完窗口停住给你看结果：

1. 把「不连云」的那几段代码拼进小程序，把 mock 运行文件拷进去 → 自检
2. 在 node 里完整打一局，**67 条断言**确认这套东西是好的

跑到 `DONE. Local test mode is ON.` 就成功了。中途报 `*** FAILED ***` 就把它截图发我。

## 第 3 步：导入项目

1. 左侧选 **小程序**（不是小游戏）
2. 点 **「+」** 或 **「导入项目」**
3. **目录**：选 `guess-player`（包含 `project.config.json` 的那一层，不是再里面的 `miniprogram`）
4. **AppID**：点 **「使用测试号」** 就行 —— 本地测试模式不连云，不需要真 AppID
5. **后端服务**：不用勾
6. 点 **确定**

> 常见坑：提示「不是合法的小程序项目」，99% 是目录选错层级，往上退一层试试。

第一次编译 5~20 秒，模拟器出首页，**并且会弹一个「本地测试模式」的小提示** ——
看到它说明你走对了路。

## 第 4 步：开始玩

| 你点的 | 会发生什么 |
| --- | --- |
| **每日一题** | 进入当天那一局（每天一道，重进是同一题） |
| **自由练习** | 随机抽一题，可以无限次开新局 |
| 底部 **搜索框**（游戏页） | 输入 `mx` / `梅西` / `messi` / `C罗` / `阿森纳` |

猜的时候依次看 8 行线索：**绿 = 完全一致、黄 = 接近、灰 = 完全不对**

- 年龄/身高/球衣号：带 ↑↓ 箭头，告诉你答案更大还是更小
- 俱乐部：同联赛判黄
- 位置：同大类（门将/后卫/中场/前锋）判黄

**8 次机会用完或猜中都会进结果页**，结果页能生成战绩图。

两个提效的小功能：

- **点线索卡上任意标签** → 弹出还符合条件的球员，点谁就直接提交（不用再打字）
- **音效**：6 种，全部由代码现场合成，设置页可单独关

## 第 5 步：本地测试模式专用的两个甜点

- **设置页 → 本地测试 → 换一道每日一题**：每日一题一天只有一道，自测时很憋屈，
  点它就能清掉本机对局、重新抽一道（正式包没有这个入口）
- **设置页 → 本地测试** 的说明文字，随时提醒你当前不是正式版

## 想切回正式版（提审前必做）

双击 `scripts\关闭本地测试-提审前必点.bat`，它会拆掉所有 MOCK 段、删掉 mock 文件，
再跑一遍 `check-mp.js`（**15 条全绿**才算干净）。然后照路线 B 配云环境。

# 路线 B：真·云环境（要提审就走这条）

> 先双击 `scripts\关闭本地测试-提审前必点.bat` 切回正式版，再往下做。

## 一、准备（一次性，约 25 分钟，主要在等）

### 第 1 步：注册小程序 + 备案

- [微信公众平台](https://mp.weixin.qq.com) → 注册 → **个人主体**
- 类目填 **工具 → 效率**（别选「游戏」，个人主体不给过）
- 备案：小程序后台有入口，**1~20 个工作日**，这一步最慢，**先办它再干别的**

> ⚠️ **AppSecret（32 位十六进制那串）不要填进任何文件，也不要发给任何人。**
> 本项目走云开发，代码里一处都用不到它。要填的是 **AppID** —— `wx` 开头的 18 位，两者不是一回事。

### 第 2 步：开通云开发，拿到环境 ID

> **「云开发」按钮点不了 / 灰的 —— 先照这张表自查**（按概率从高到低）
>
> | 原因 | 怎么查 / 怎么修 |
> | --- | --- |
> | ① `project.config.json` 里的 `appid` 还是占位值 `touristappid` | 这是最常见的一条。**任何人克隆下来都得改**（开源仓库里故意留占位，不公开真 AppID）。去 mp 后台复制你自己的 AppID，回来在「详情 → 基本信息 → AppID」改掉 |
> | ② 开发者工具**没登录**，或登录的微信不是该小程序的管理员 | 右上角头像区扫码，必须是**注册小程序那个微信**本人 |
> | ③ 小程序信息没填完（名称 / 头像 / 简介 / 类目） | mp 后台 → 设置 → 基本设置，补齐再回来点 |
> | ④ 开着代理 / 科学上网 | 关掉，重启开发者工具 |
> | ⑤ 用的是**测试号** | 测试号永远没有云开发，只能走路线 A（本地测试模式） |

开发者工具左上角 **云开发** → 开通（有免费额度，个人够用）→ 新建环境 →
复制 **环境 ID**，形如 `guess-player-1a2b3c4d`

填进 `miniprogram/app.js`：

```js
const ENV_ID = 'guess-player-1a2b3c4d';   // ← 换成你自己的
```

> 这是全项目**唯一必须手改的地方**。云函数里用的是 `cloud.DYNAMIC_CURRENT_ENV`，不用改。
> 填错了首页会直接显示「云环境没连上：请把 miniprogram/app.js 的 ENV_ID 换成……」。

### 第 3 步：建集合和索引

云开发控制台 → 数据库 → 新建集合：`players`、`games`、`meta`
（权限全部选**「仅创建者可读写」**，别选「所有用户可读」——答案就靠这层守）

索引照 `docs/05-deployment.md §3` 建，最关键的是 `games.uniqueKey` 的**唯一索引**，
没有它高并发时会开出两局。

### 第 4 步：导入题库 + 上传云函数

```bash
# 1. 云开发控制台 → 数据库 → players 集合 → 导入
#    选 database/players.full.jsonl（500 条）
#
# 2. meta 集合手动加三条文档（照 docs/05-deployment.md §4 抄）
#
# 3. 同步 shared 代码到每个云函数目录
#    （微信只上传单个函数目录，不同步就 MODULE_NOT_FOUND）
node scripts/sync-shared.js
#
# 4. 开发者工具里：右击每个 cloudfunctions/xxx 目录 → 「上传并部署：云端安装依赖」
#    一共 5 个：gameStart / gameGuess / gameResume / gameResult / getPlayers
```

### 第 5 步：导入项目

跟路线 A 第 3 步一样，但 **AppID 必须填你自己的**（测试号跑不了云开发），
并且 **后端服务 勾上「微信云开发」**。

# 自测清单（照着勾就行）

提审之前，建议按这个顺序点一遍，能覆盖所有主要路径：

- [ ] **首页**：显示今天的日期、每日一题状态（未完成 / 已答对 X/8）
- [ ] **每日一题** → 进来有棋盘，顶部显示剩余次数 8
- [ ] 点搜索框，输入 `mx` → 出现梅西；`C罗` → 出现 C 罗
- [ ] 猜一个人 → 出现一行线索，带颜色，次数变成 7
- [ ] 故意再猜同一个人 → 提示「已经猜过 TA 了」，**次数还是 7**（不消耗）
- [ ] 连着猜错 8 次 → 进入结果页，显示 X/8、答案是谁
- [ ] 结果页 → 点「生成战绩图」→ 能出图、能保存
- [ ] 回首页 → 每日一题显示「已结束」，点进去直接看结果
- [ ] **自由练习** → 能连续开新局（每次都是新题）
- [ ] 游戏进行到一半 → 杀掉小程序重进 → 线索还在（续局成功）
- [ ] 猜完后**点线索卡上的「右脚」这类标签** → 弹出候选面板，列出的全是符合该条件的人
- [ ] 候选面板里每名球员都摊开了 **8 项线索**（两列），能直接和上面线索卡逐项对照
- [ ] 在面板里多勾几个标签 → 人数变少，但**答案始终还在列表里**（这是设计保证）
- [ ] 面板里点一名球员 → 直接提交，消耗 1 次机会
- [ ] 猜中时有一串上行音、猜错是短促下滑音、`设置页 → 音效` 关掉后全部静音
- [ ] **设置页** → 关掉振动 → 猜一个人，确认手机不震了
- [ ] **设置页** → 战绩里有刚才那几局的分布

发现不对的地方直接告诉我，报「哪个页面 + 点了什么 + 看到什么」就行。

# 自动化验证

不想手动点，或者改了代码想确认没改坏：

```bash
scripts\一键测试.bat          # 双击即可，8 段全绿才准提审
```

各段干的事：

| 脚本 | 断言数 | 校验内容 |
| --- | --- | --- |
| `test-compare.js` | 32 | 判定规则、公差、年龄计算、抽样发散度（**modHex 精度**） |
| `test-flow.js` | 77 | 5 个云函数端到端、并发幂等、越权、**答案零泄露** |
| `test-search.js` | 51 | 真实搜索输入 41 条、索引一致性、歧义词排序 |
| `test-candidates.js` | 36 | 线索筛选语义、**答案永不被筛掉**（1.1 万次筛选）、与服务端口径对拍 |
| `test-sfx.js` | 24 | 音效参数安全区间、调用点没错名字、设置开关 |
| `test-rank.js` | 66 | 得分口径手算对拍、**等宽补零（字符串排序须等于数值排序）**、托管 KV 约束、最佳记录 |
| `check-mp.js` | 13 / 15 | JSON 合法性、组件路径、**事件绑定是否有对应方法**、Mock 开关状态 |
| `simulate.js` | — | 难度验收（机器人最坏步数 ≤ 8，即没有死题） |
| `validate.py` | — | 500 条球员数据的字段、译名、search_index |

**合计 299 条断言**（32+77+51+36+24+66+13）。

`check-mp.js` 的条数随模式变：本地测试模式 **13 条**（含「配套文件齐全」），
正式版 **15 条**（含「没有残留的 mock-*.js」）。

### 单独跑：题库体检（`audit-data.py`，不进一键测试）

```bash
python scripts/audit-data.py                 # 基准日取 jsonl 里的 data_as_of
python scripts/audit-data.py 2026-10-11      # 指定基准日算年龄
```

它**只报不改**，输出三块：分布总览（位置/惯用脚/联赛/国籍/俱乐部/年龄段）、
可疑项清单、待人工核对项。和 `validate.py` 的分工是：

| | `validate.py` | `audit-data.py` |
| --- | --- | --- |
| 管什么 | 字段合不合法（译名、枚举、search_index） | 数据好不好用（分布、跨记录冲突、死题） |
| 不合格时 | **阻断**，不许导入 | 只报告，退出码只看死题 |

为什么需要第二个：字段全合法 ≠ 游戏可玩。比如两个球员在 8 条线索上取值完全相同，
`validate.py` 一条都抓不到，但玩家永远无法区分他们 —— 这是逻辑死题，只能跨记录比对发现。
**扩过题库之后跑一遍**，顺带看分布是不是又偏了。

本地测试模式还有一段自己的回归，由 `开启本地测试.bat` 自动跑：

| 脚本 | 断言数 | 校验内容 |
| --- | --- | --- |
| `test-mock.js` | 67 | 整局打通、**手写 SHA-256 与 node crypto 逐字节对拍**、api.js 双路路由 |

### 改完数据记得重跑

```bash
python scripts/build-players.py
python database/validate.py database/players.full.jsonl <日期> --fix
node scripts/sync-shared.js        # 改过 _shared/ 后必跑
node scripts/toggle-mock.js on     # 如果在本地测试模式，重跑一下同步算法副本
```

# 出问题先看这里

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 「不是合法的小程序项目」 | 导入目录选错了，要选包含 `project.config.json` 的那层 |
| **「云开发」按钮点不了 / 灰的** | 见「路线 B 第 2 步」开头那张自查表，99% 是 AppID 还是模板里的假值 |
| 云开发控制台里 `cloudfunctions` 显示「未选中」 | 云环境还没开通，或没在「云开发 → 设置 → 环境」里选中环境（开通后自动选中） |
| 首页写「云环境没连上……」 | `app.js` 的 `ENV_ID` 还是模板里的假值，换成你自己的 |
| 首页写「云函数还没上传……」 | 右击 `cloudfunctions/xxx` → 上传并部署（5 个都要） |
| 首页写「数据库集合还没建……」 | 建 `players` / `games` / `meta` 三个集合，并导入题库 |
| 模拟器空白，控制台报 `MODULE_NOT_FOUND` | 云函数里的 `_shared` 没同步，跑 `node scripts/sync-shared.js` |
| 没有任何报错但页面不渲染 | 跑 `node scripts/check-mp.js`，多半是组件没注册 |
| 搜索什么都搜不到 | 本地测试模式下重启小程序；云模式看 `players` 集合是否导入 |
| 猜完没有反应，一直转圈 | 打开控制台看是不是报了某个 code（1005=重复、1002=对局不存在） |
| 换了一天，每日一题还是那道题 | 日期用的是 UTC+8 自然日，跨零点要等过了北京时间 0 点 |
| 点线索标签没反应 | 只有对局进行中才能点（猜完那一局就锁了） |
| 筛选面板里人数是 0 | 条件互相打架，去掉一个再试（正常情况不会出现） |
| 一点声音都没有 | 先看设置页「音效」是否开着；iOS 还要看左侧静音拨片 |
| 双击 .bat 一闪而过 | 说明它自己报错了但没停住，改用命令行跑 `node scripts/toggle-mock.js on` 看报错 |
| 上线后用户说玩不了 | 99% 是没备案，或者 `games` 集合权限设成了「仅管理端可读写」 |

> **「GitLens was unable to find Git」跟本项目无关。**
> 那是代码编辑器自带的 Git 增强插件在抱怨你机器上没装独立的 Git
> （编辑器内部可能带了个便携版，但那个路径它自己看不到）。
> 小程序能不能编译、能不能提审、能不能开通云开发，跟 Git 一点关系都没有 ——
> **本项目从头到尾没有用到 git**，这个提示可以永远忽略。
>
> 嫌它反复弹：点通知右边的 **∨ 下拉箭头** → 选「不再显示」，或者直接在扩展列表里禁用 GitLens。
>
> 什么时候才真需要装 Git：将来你想把代码托管到 GitHub、或者用版本管理回滚代码的时候。
> 项目里已经备好 `.gitignore`（挡住 `project.private.config.json`、`secret.*` 等），到那天再说。

# 现在这个包的构成

```
guess-player/
├── miniprogram/            小程序本体
│   ├── pages/              5 个页面：首页 / 游戏 / 结果 / 规则 / 设置
│   ├── components/         clue-card 线索行 · search-sheet 搜索面板
│   │                       candidate-sheet 点标签筛选面板 · player-badge 程序化头像
│   └── utils/              api · search · share · storage · theme
│                           age 年龄 · clue 线索筛选 · sfx 音效
│                           （本地测试模式下会多出 6 个 mock-*.js，提审前会被删掉）
├── cloudfunctions/         5 个云函数 + _shared/（判定与抽样的单一真源）
├── database/               players.full.jsonl（500 人）+ roster_{a..g}.py + validate.py
├── scripts/                构建、同步、测试脚本
│   ├── 一键测试.bat                      8 段全量回归
│   ├── 开启本地测试.bat                  ← 想立刻看效果就双击它
│   └── 关闭本地测试-提审前必点.bat        ← 提审前必须双击它
├── docs/                   01-PRD · 02-database · 03-algorithm · 04-testing · 05-deployment
├── _mock-backup/           本地测试模式的存档：mock-*.js + 代码块 + 还原说明（不进包，也不上传）
└── README-启动.md          本文件
```
