# 本地测试模式（不连云）存档与开关

这套东西让小程序**不连任何云服务**也能完整玩一局：5 个「云函数」在客户端跑，
数据存在本机 storage。所以不需要 AppID、不需要 ICP 备案、不需要云开发环境。

## 怎么用（不用手抄任何代码）

```
scripts\开启本地测试.bat                ← 开启，然后打开开发者工具编译即可玩
scripts\关闭本地测试-提审前必点.bat     ← 关掉，提审 / 上线前必须点
```

等价于：

```bash
node scripts/toggle-mock.js on
node scripts/toggle-mock.js off
node scripts/toggle-mock.js status
```

## ⚠️ 为什么提审前必须关掉

开启后，**比对逻辑和 500 人答案池都在客户端**（`mock-compare.js` + `mock-players.js`）。
任何人下载小程序包、反编译后遍历候选池，就能把每天的答案试出来 ——
这直接违反项目架构红线（见 `docs/03-algorithm.md`）。

关闭脚本会：拆掉全部 MOCK 段 → 删掉 6 个 `mock-*.js` 和 3 个 mock 脚本 →
跑一遍 `check-mp.js`（**15 条全绿**才算干净）。

## 它是怎么做到「拆完跟原来一模一样」的

`scripts/toggle-mock.js` **不保存两份整文件**，而是在现场拼装：

- `_mock-backup/blocks/*.txt` 存的是 10 个**带标记的代码片段**，
  每段都包在 `/* >>> MOCK-BEGIN ... <<< */` 和 `/* <<< MOCK-END <<< */` 之间
- `on`：先 `strip()` 掉可能残留的段落，再按锚点把片段插进**当前的正式文件**
- `off`：只把带标记的段落整体删掉（连逗号都写在标记里面），多余的空白行收掉

**两个方向往返任意次，结果都逐字节一致**（已实测 3 轮 SHA-256 比对）。

为什么不存两份整文件：那样今天改了 `settings.js`、忘了同步副本，
明天就会被旧代码覆盖新版，而且**不报错**。拼装则相反 ——
正式代码结构一变，锚点找不到，它当场停下来告诉你该改哪一段。宁可停，不要悄悄跑起一份过期界面。

## 目录内容

```
_mock-backup/
├── utils/                  6 个 mock-*.js（on 时拷进 miniprogram/utils/）
│   ├── mock-api.js         5 个「云函数」的客户端实现（对局存在 storage）
│   ├── mock-players.js     200 名球员数据（22 字段）
│   ├── mock-compare.js     判定算法（_shared/compare.js 的自动副本）
│   ├── mock-constants.js   常量（_shared/constants.js 的自动副本）
│   ├── mock-util.js        抽样/工具（_shared/util.js 的自动副本）
│   └── mock-hash.js        SHA-256 手写实现（替换 node crypto，与标准库逐字节对拍过）
├── scripts/                on 时拷回 scripts/
│   ├── test-mock.js        67 条断言：整局跑通 + SHA-256 对拍 + api.js 双路路由
│   ├── gen-mock-core.py    从 _shared/ 重新生成上面三个算法副本
│   └── gen-mock-data.py    从 players.full.jsonl 重新生成 mock-players.js
├── blocks/                 10 个待拼装的代码片段（见上）
└── 还原说明.md             本文件
```

> `scripts/mock-cloud.js` **不在这里**，也从来没被删过 —— 它是给**真云函数**在 node 里跑测试的
> 内存数据库，`test-flow.js` / `simulate.js` 依赖它。名字像，别跟 mock 模式搞混。

## 改了 `_shared/` 之后

本地测试模式的算法是 `_shared/` 的**自动副本**（不是手抄），所以要重新生成：

```bash
python scripts/gen-mock-core.py     # 重新生成 mock-compare / mock-constants / mock-util
python scripts/gen-mock-data.py     # 题库改了才需要
node scripts/toggle-mock.js on      # 或者直接双击「开启本地测试.bat」，它会重装一遍
```

> `_shared/` 改了也要跑 `node scripts/sync-shared.js` —— 那是给云函数用的，跟这边是两回事。

## 几个已知的行为

- 开启后小程序会弹一个「本地测试模式」的 toast，`console.warn` 也会说一遍
- 设置页会多出「本地测试 → 换一道每日一题」（一天只有一道题，自测时用得上）
- 每日抽样、答案池分档（`MIN_FAME_DAILY`）、`status==='playing'` 守卫全都跟真云函数一致，
  返回体逐字段对齐 `{ ok, code, msg, data }` 信封 —— 所以切回云模式前端一行都不用改
