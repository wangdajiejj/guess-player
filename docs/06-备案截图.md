# 备案材料：3 张截图怎么截 + 表单怎么填

> 对应微信后台「小游戏备案 → 填写游戏内容 / 提交材料」这两步。
> 前置阅读：`docs/05-deployment.md §2` 后台首页五块。

---

## 0. 先确认一件事：你的账号到底是哪一类

**这一步没确认就往下做，可能白花两个月。**

小程序和小游戏是**两个独立的账号类型**，注册时就定死了，**不能互相转换**：

| | 小程序账号 | 小游戏账号 |
| --- | --- | --- |
| 后台左侧菜单 | 设置 / 成员管理 / 第三方设置 / 订阅消息 | **游戏能力地图 / PC小游戏 / 流量主 / 广告主 / 虚拟支付** |
| 代码形态 | WXML + WXSS + 页面路由 | Canvas / 游戏引擎 |
| 备案走哪条 | **小程序备案**（1~20 工作日） | **小游戏备案**（要软著 + 自审报告，约 10 工作日） |
| 软著 | 不需要 | **必须有**（个人申请 2~3 个月） |
| 个人主体可行性 | ✅ 完全可行 | ⚠️ 可行但周期长 |

**怎么判断**：登录 mp 后台 → 点左侧最上面的「首页」→ 看页面标题栏写的是「小程序」还是「小游戏」。

> ⚠️ 注意一个陷阱：微信后台的**小游戏备案页面**（地址里带
> `subApp/game/minigame_new_pre_approval_file`）是一个**可以直达的 URL**。
> 即使你是小程序账号，别人给你这个链接你也能打开、能填表 ——
> 但**提交后不会走通**，因为小程序账号没有游戏类目，也交不了软著。
> 看到这个页面不等于「我是小游戏账号」，一定要回首页确认。

### 两条路的成本对比

| | A. 改注册小游戏账号 | B. 用现有小程序账号（推荐） |
| --- | --- | --- |
| 重新注册 | 要 | 不用 |
| 软著 | **必须**，2~3 个月 | 不需要 |
| 游戏自审报告 | 必须（约 30 页） | 不需要 |
| 小游戏备案 | 必须 | 不需要 |
| 小程序备案 | 不需要 | 必须（1~20 工作日） |
| **代码要不要重写** | **要**（UI 全部改 Canvas，等于重写前端） | 不用，当前这版直接提 |
| 类目 | 游戏类目 | **工具 → 效率** |
| 虚拟支付 / 流量主 | 可开 | 个人主体不能开 |
| 预估周期 | 3~4 个月 | 1~3 周 |

**如果你只是觉得「都做到这一步了不想改」—— 走 B 更划算。**
B 通过后功能和现在完全一样，只是后台类目写「工具」，玩法包装成「足球资料查询 / 知识练习」。
`docs/05-deployment.md §7` 里有 B 路的提审话术，可直接用。

**如果你确实要走 A**：先把软著申请起来（2~3 个月，边等边改 Canvas），
截图这步照下面做，但注意最后一节 §5 的形态一致性问题。

## 1. 截图的硬性要求（照这个核对，缺一项会被打回）

| 项目 | 要求 |
| --- | --- |
| 数量 | **3 张以上**（建议交 4 张，上限 5 张） |
| 格式 | JPG / PNG |
| 单张大小 | **60 KB ~ 5 MB** |
| 来源 | **微信客户端里的真实截图**（手机截屏），不能用设计稿、不能用 PS 图 |
| 内容 | 截内能看出是当前这个小游戏 / 小程序 |
| 清晰度 | 不能模糊、不能有黑边、不能拉伸变形 |

> ⚠️ **不要用开发者工具模拟器截图**。模拟器没有微信外壳，
> 审核可能判定「不是微信版截图」。一定要**手机扫码预览后截屏**。

---

## 2. 前置：让项目先在手机上跑起来

### 第 1 步：开本地测试模式

双击项目根目录的：

```
开启本地测试.bat
```

看到「已切到本地测试模式」即可。

> 为什么用本地测试模式截图：它**不连云、不用配云环境**，
> 手机扫码就能完整玩一局。你现在还没配云开发，这是唯一能马上出图的路子。
> 正式环境配好后（`docs/05-deployment.md §3`），可以再截一次替换，但不必等。

### 第 2 步：开发者工具打开项目

微信开发者工具 → 导入项目 → 目录选 `guess-player/miniprogram`
→ **填入你自己的 AppID**（不要选「测试号」，测试号没法预览到手机）

### 第 3 步：预览到手机

开发者工具右上角 → **预览** → 手机微信扫二维码。

> ⚠️ 预览码 **25 分钟有效**。建议先把下面 §3 的步骤看一遍再扫码，
> 免得扫完还在想下一步，码过期了要重新扫。

### 第 4 步：避开启动提示

刚打开时会弹一个 Toast：**「本地测试模式」**，约 1.8 秒后消失。

> ⚠️ 这个提示**不能出现在备案截图里**（会让人以为是不完整版本）。
> 进入页面后**等 2 秒再截**。

---

## 3. 四张截图，逐张拍

### 📷 第 1 张：首页

**操作**：扫码进去就是首页，等 2 秒 → 截屏。

**画面里必须有**：
- 顶部「猜球员」标题
- 「每日一题」卡片（带当天日期 + 「开始今日挑战」按钮）
- 「自由练习」卡片
- 底部战绩区（已玩 / 胜率 / 当前连胜 / 最长连胜）

> 如果首页显示「今天的状态没能加载出来」—— 说明每日一题没起来，
> 检查本地测试模式是否真的开了（重跑 `开启本地测试.bat`）。

---

### 📷 第 2 张：对局进行中（**最重要的一张**）

这张是审核员判断「你这游戏到底怎么玩」的关键。

**操作**：
1. 首页点「**开始今日挑战**」→ 进入游戏页
2. 点底部「**选择球员**」→ 弹出搜索面板
3. 搜索框随便输一个球员名（如「梅西」）→ 点搜索结果 → 提交
4. **重复第 2~3 步，一共猜 3 次**

**画面里必须有**：
- 顶部「剩余机会 X/8」
- 进度点（已猜的 3 个点变深色）
- **3 张线索卡**，每张 8 行（国籍/俱乐部/联赛/位置/年龄/身高/球衣号/惯用脚）
- 线索卡上要能看出**绿 / 黄 / 灰三种颜色**和**箭头**

> 💡 **怎么保证三色齐全**：提交后颜色是系统判的，随机。
> 如果 3 次猜下来全是灰、不好看，去**设置页底部**点「换一道每日一题」重开一局，
> 多试两次就能截到颜色丰富的画面。这个按钮只有本地测试模式有，提审前会消失。

---

### 📷 第 3 张：线索筛选面板（**你的独有功能，强烈建议交**）

**操作**：在第 2 张的界面上，**点线索卡上的任意一个标签**（比如「右脚」「英超」「中后卫」）
→ 弹出候选球员面板。

**画面里必须有**：
- 顶部显示启用的筛选条件
- 候选球员列表（每人一行，摊开 8 项线索）
- 面板底部的人数统计

> 这是你和普通猜谜游戏不一样的地方，交上去能让审核更快理解玩法。

---

### 📷 第 4 张：结果页

**操作**：在第 2 张的界面上**继续猜，把 8 次机会用完** → 系统自动跳结果页。

（如果中途猜中了也会自动跳，同样可以截。）

**画面里必须有**：
- 顶部结果横幅（「猜中了！」或「很遗憾」+ 得分）
- 答案球员卡（头像 + 中文名 + 英文名 + 位置标签）
- 「他是谁」简介段落

> ⚠️ 结果页底部有一行小字「小头像由球队配色现场绘制，非照片或肖像」——
> **这行不用遮**，它恰恰是合规加分项，留着。

## 4. 表单三个框的成稿（可直接复制粘贴）

### ① 场景（≥30 字）

```
游戏主界面为深绿色主题，顶部显示"足球猜球员"标题与当日日期，中部为球员头像圆形占位区与
8 行线索卡片（国籍、俱乐部、联赛、位置、年龄、身高、球衣号、惯用脚），每行用绿/黄/灰三色
与上下箭头提示接近程度。底部为"输入球员名搜索"输入框与 8 个逐次点亮的猜测次数圆点。
```

### ② 玩法（≥50 字）

```
每次对局系统从球员库中随机选定一名球员作为答案，玩家通过搜索框输入球员名进行猜测，
每猜一次系统回填该球员的 8 项属性线索并显示与答案的匹配程度：绿色代表完全一致，
黄色代表接近（同联赛 / 同位置大类 / 数值在公差范围内），灰色代表不符，数值类线索
额外用红涨绿跌箭头提示偏高还是偏低。玩家每局最多猜测 8 次，猜中或次数用尽后进入
结果页揭晓答案并展示球员简介。每日更新一名答案，另设自由练习模式可不限次数重开。
```

### ③ 系统功能（下拉多选 + 每个都要写说明）

**只勾这两项：「设置系统」+「自定义定义」，其余全部不要选。**

| 选项 | 勾不勾 | 原因 |
| --- | --- | --- |
| 货币 / 商城 / 兑换码 / 会员VIP / 道具 / 体力 | ❌ | 你没做商业化，勾了要额外说明，徒增审核面 |
| **排行榜** | ❌ **千万别勾** | 个人主体**禁止 UGC**，排行榜涉用户数据展示，是硬红线 |
| 设置系统 | ✅ | 你确实有音效开关、清除缓存、关于页 |
| 自定义定义 | ✅ | 用来说明「线索筛选」这个独有功能 |

**「设置系统」说明：**
```
玩家可在设置页开启或关闭游戏音效（含开关状态本地保存），查看版本号与关于信息，
并可清除本地缓存的球员数据以释放存储空间。设置项均为本地生效，不涉及账号与支付。
```

**「自定义定义」说明：**
```
线索筛选系统：玩家可点击已猜球员反馈出的线索标签（如"右脚""英超""中后卫"），
系统会依此过滤出符合该条件的候选球员列表，方便在剩余球员中继续缩小范围。
该筛选仅基于玩家已看到的反馈信息进行，不会泄露答案，也不涉及任何付费内容。
```

## 5. 常见坑

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 截图里有「本地测试模式」Toast | 开本地测试模式后前 1.8 秒会有。等 2 秒再截 |
| 预览码过期 | 25 分钟有效，过期重新点「预览」扫码 |
| 模拟器截图被判不合规 | 必须手机扫码后截屏，模拟器没有微信外壳 |
| 单张图小于 60 KB | 手机原图一般 1~3 MB，不会太小。若真太小说明截图区域裁太小了，重截 |
| 单张图大于 5 MB | 用系统「照片」编辑器另存为 JPG，或截屏时只截画面区域去掉多余状态栏 |
| 每日一题一天只有一道，试不出好看的颜色 | 设置页底部「换一道每日一题」（仅本地测试模式有） |
| 走 A 路但截图是小程序形态 | 小游戏要求 Canvas 形态，当前 WXML 界面截出来会被判「截图与代码形态不符」。**这是 A 路必须先重写 UI 的原因** |
| 提示「请先提交材料」 | 小游戏备案前要先交软著等资质，小程序账号交不了这个 |

---

## 6. 提交后

1. 材料提交后进入「平台初审 → 管局审核 → 平台审核」，一般 **10 个工作日**
   （各省管局速度不同，广东较快，偏远省份可能到 20 天）
2. 审核期间留意**负责人手机短信**，管局会打电话核验，**漏接会直接驳回**
3. 通过后：小程序备案 → 版本提审 → 发布

回到 `docs/05-deployment.md §7` 看提审要点与话术。
